# Краткая инструкция: Новые возможности Dashboard

## 🎯 Что добавлено

### ⚙️ Расширенная конфигурация (Sidebar)

**Новые параметры:**

1. **Режим работы**
   - ✅ Ручная проверка данных после экстракции
   - ✅ Автоматическое скачивание attachments

2. **География поиска**
   - Только локальные компании
   - Локальные + региональные (по умолчанию)
   - Национальный поиск
   - Настраиваемый радиус (50-500 км)

3. **Количество результатов**
   - Слайдер: 50 - 1000 компаний

4. **Обогащение данных**
   - Google Maps API
   - Apollo API  
   - Автоматическое обогащение при отсутствии контактов

---

## 📝 Редактор экстракции

**Где:** Вкладка "Extracted Data" → "Edit Extraction"

**Возможности:**
- Исправить город, штат, страну
- Добавить/изменить NAICS коды
- Исправить set-aside программы

**Как использовать:**
1. Запустить pipeline
2. Проверить извлеченные данные
3. Открыть "Edit Extraction"
4. Исправить ошибки
5. Нажать "Save Changes"
6. Запустить pipeline снова

---

## 💎 Ручное обогащение вендоров

**Где:** Вкладка "Vendors" → "Manual Enrichment"

**Статусы контактов:**
- ✅ Полные (email + телефон)
- ⚠️ Частичные (только email или телефон)
- ❌ Отсутствуют

**Методы обогащения:**

### 1. Массовое обогащение
```
🗺️ Batch Enrich via Google Maps - обогатить все компании через Google Maps
🚀 Batch Enrich via Apollo - обогатить все компании через Apollo
```

### 2. Индивидуальное обогащение
Для каждой компании:
- `🗺️ Google Maps` - поиск через Google Maps
- `🚀 Apollo` - поиск через Apollo
- `✏️ Manual Entry` - ручной ввод контактов

## 💡 Полезные советы

### Экономия API вызовов
- Используйте `gpt-5-mini` для тестирования
- Включайте Flex Tier
- Ограничивайте Max Vendors разумным числом

### Точность результатов
- Включайте Manual Review для важных контрактов
- Проверяйте извлеченные NAICS коды
- Используйте Custom Radius для точного поиска

### Обогащение контактов
- Сначала используйте Google Maps (бесплатный лимит)
- Apollo для B2B компаний
- Manual Entry для критичных вендоров

## 🔑 Настройка API ключей

Создайте `.env` файл:

```bash
# Обязательно
OPENAI_API_KEY=sk-...

# Опционально для обогащения
GOOGLE_MAPS_API_KEY=AIza...
APOLLO_API_KEY=...
```

Проверить статус ключей можно в sidebar → "🔑 API Keys Status"

## 📥 Экспорт результатов

**3 способа:**

1. **CSV** (в таблице vendors)
   - Кнопка "📥 Download Results as CSV"

2. **Excel/CSV/JSON** (внизу после pipeline)
   - Кнопка "💾 Save as Excel"
   - Сохраняется в `outputs/` директорию

3. **Custom Export**
   - Кнопка "📥 Download CSV" (внизу)
   - Включает все поля + rationale

## ❓ Частые вопросы

**Q: Кнопки обогащения не работают?**  
A: Нужна интеграция с GoogleMapsProvider и ApolloProvider. Пока доступен только Manual Entry.

**Q: Как изменить количество результатов?**  
A: Sidebar → "Results Settings" → "Max Vendors to Return"

**Q: Как искать только рядом?**  
A: Sidebar → "Geographic Scope" → "local_only" или "custom_radius"

**Q: Изменения в редакторе не применяются?**  
A: После "Save Changes" нужно нажать "🚀 Run Pipeline" снова

**Q: Слишком много/мало вендоров?**  
A: Настройте:
- "Geographic Scope" (шире/уже)
- "Max Vendors" (больше/меньше)
